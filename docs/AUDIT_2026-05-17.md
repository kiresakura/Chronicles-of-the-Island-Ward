## 🟠 P1 — 戰鬥邏輯錯誤（已修 / 待修）

### B3. ✅ **已修** — 敵人 status target_override 全部錯

5 個敵人 attack 用 `target_override: 3` (ALL_COMBATANTS) 給玩家施加 debuff，但這會**同時影響自己 + 其他敵人**。

最嚴重：椅仔姑 `summon` attack 想給**自己**神威用 `target_override: 2` (PLAYER)，結果**給玩家加神威**，戰鬥反向爆炸。

| 敵人 | 舊值 | 新值 | 意圖 |
|---|---|---|---|
| 椅仔姑 summon (給自己神威) | 2 (PLAYER) ❌ | **1 (PARENT)** | 給敵人自己 |
| 椅仔姑 haunt (給玩家怯戰) | 3 (ALL_COMBATANTS) ❌ | **2 (PLAYER)** | 給玩家 |
| 樹靈 (給玩家怯戰) | 3 ❌ | **2** | 給玩家 |
| 虎姑婆 (給玩家驚嚇) | 3 ❌ | **2** | 給玩家 |
| 魔神仔 lure (給玩家驚嚇) | 3 ❌ | **2** | 給玩家 |

**修法**：批次 sed 改值。已驗證 5 個敵人 JSON 內容正確。
**狀態**：✅ 已修（本次 audit）

## 🔵 P4 — 優化建議

### O1. 直向 UI 重設計（Sprint 2 主任務）

當前 landscape + stretch 是應急。Sprint 2 要切 portrait 1080×2340 + 全新 layout。

### O2. 卡牌動畫 / 視覺反饋

STR 預設只有最低限度動畫（fade in/out）。要加：
- 出牌軌跡（lerp + ease）
- 卡牌懸停預覽放大
- 戰鬥傷害浮字（"6" 飛出）
- 角色受擊閃紅
- 敵人意圖預告動畫

### O3. 觸控優化

PRD 5.2 寫了觸控手勢但 STR 原版是滑鼠：
- 上滑卡牌（無目標） → 自動出
- 拖曳卡牌 → 指定敵人
- 長按 → 詳情
- 雙指 pinch → 縮放戰場

要在 Hand.gd / Combat.gd 加觸控 input handler。

### O4. 音效（PRD 9.2）

完全沒音效。要加：
- 出牌 = 擲筊聲（聖筊）
- 受擊 = 木魚 / 銅鈸
- 法術 = 符紙撕裂、念咒回音
- BGM = 北管 / 南管 + 電子鼓

### O5. CJK 字型內嵌

iPhone fallback PingFang 可用，但 Android / desktop 可能字型不齊。內嵌思源黑體 / Noto Sans CJK。

### O6. 觸控目標尺寸

按鈕 44×44 pt（蘋果 HIG）— Sprint 2 直向重設計時要保證。

### O7. Boot splash 真機驗證

升級設計：剪黏紋路 placeholder、淡入 fade、加 loading dots。

### O8. 「上次玩過」記憶

iPhone 重開遊戲應該記得上次選的角色 / 進度。STR 有 autosave 但角色預選 UX 可加強。

### O9. 角色職業預覽動畫

選角介面要有 idle 動畫 + 起手卡組預覽。

### O10. Difficulty 0 預設鎖死

直到 run_modifier 資料寫完前，鎖死 difficulty=0 防止 crash。
