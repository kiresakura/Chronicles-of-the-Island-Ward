# 美術生產標準（Art Production Standard）— 像素 SSOT

> **定位**：`COTIW_UI_UX_ART_DIRECTION.md` 是**願景**（風格、氣質、色票哲學）；本檔是**可被測試強制的規格**（數字、流程、守門規則）。
> 兩者衝突時，願景定方向、本檔定執行。本檔由 `tools/art_lint.py` 強制；過不了 lint 的圖**不准進 `assets/`**。
> **建立**：2026-06-20，承接美術審判（八宗罪）與「全像素・封存插畫」拍板。

---

## 0. 唯一鐵則（拍板）

**全像素・封存插畫。** 所有**同屏世界物件**（角色立繪、敵人、卡面、FX、場景、UI 圖示）服從**單一像素真相**。平滑動漫渲染**只准**出現在**非敘事 key-art**（標題、圖鑑全身展示、商店 banner），且必須量化到同一像素感，**永不與像素 sprite 並肩同屏**。此鐵則與 `CLAUDE.md` §4「Temple Neon Pixel」一致，無需改鎖定決策。

---

## 1. 像素階梯（尺寸）

| 用途 | 原生畫布 | 顯示 | 備註 |
|---|---|---|---|
| 戰鬥單位（角色/敵人）單幀 | **128×128** | 整數倍 | 不是 759×996 那種自動裁切怪尺寸 |
| 動畫條 | `N×128 × 128` | 整數倍 | N＝幀數（見 §4） |
| 卡面插圖區 | **256×256** | — | 入卡框，不滿版到卡邊 |
| 圖示 / status / map node | **64×64** | 64 或 32 | 優先向量 SVG |
| 場景背景 | **長邊 ≤ 384 原生**再整數放大到 1376×768 | — | 解決「角色貼在過細背景上」 |

**鐵律**：所有邊長必為 **32 的倍數**（`art_lint: OFF_GRID`）。場景背景的像素密度（每單位像素塊大小）須與角色一致——背景在 NBP 出母圖後**降採到與角色同密度**再放大。

## 2. 調色盤

- **品牌五色**為主軸：`#8e2a1c 硃砂 / #e8c46a 燙金 / #f0e4c8 米白 / #1a0f0d 漆黑 / #46c99a 青玉`。
- 每張 sprite **唯一色 ≤ 256**（`art_lint: NOT_PIXEL` 守門）；超過＝平滑渲染洩漏。
- **霓虹是稀缺資源**：青藍/洋紅輝光只給「破煞/請神/降乩」等高光時刻，不鋪滿。

## 3. 去背法

- 硬 alpha：像素**非全透即不透**，半透明像素比例 **≤ 2%**（`art_lint: HALO`）。FX 輝光例外。
- 該去背的類型（角色/敵人/卡/圖示）**四角必透明**；實心背景＝未去乾淨（`art_lint: NO_CUTOUT`）。
- 邊緣對齊像素格，**禁止** AA 灰邊、禁止背景殘留鎖鏈/煙圈（審判罪 1 的源頭）。

## 4. 動畫法

- **真**逐幀，不是複製幀（`art_lint: FAKE_ANIM` 擋每幀相同）。
- 幀數：**4 幀/條**（PixelLab `animate-with-text` 單次連戲上限＝4；多次呼叫不連戲，已實測。對齊 `BaseCombatant.ANIM_FRAME_COUNT=4`）。更順的動畫需改走 `animate-with-skeleton` 或補間，列為後續。
- 幀間不爆跳（連戲）；FX 爆破除外。
- **共用腳底基線錨點**：每幀腳底對齊同一 baseline，禁止上下亂飄。
- 播放 fps：idle 6–8、行動 8–12（不是現在的 4fps 幻燈片，見 `BaseCombatant.gd`）。

## 5. 接地與打光

- 統一**腳底基線** + **獨立**地面影子貼花（橢圓軟影），**不**把草皮/影子烤進角色（罪 8）。
- 光源方向統一：主光左上、暖色；逆光用青藍當節奏對比。

## 6. 插畫封存法

- 平滑動漫（神明、圖鑑全身）**只准**做 key-art。若要與像素同屏 → 先過**像素量化**（降採 + 限色 + 描邊）成像素資產。
- 神明的「降乩」只在**全屏過場 cut-in** 出現，空間上不與像素 sprite 相撞。

## 8. 每類別整改地圖（產線分工）

| 類別 | 現狀病 | 目標生成器 | 目標規格 |
|---|---|---|---|
| 敵人 sprite + 動畫 | 靜態尚可、動畫條已隔離 | **PixelLab** | 128px，idle/attack/hit/death ≥6 幀真動畫，共用 baseline |
| 4 主角立繪 | `portraits_v3` 是平滑動漫（非像素） | **PixelLab**（母圖 NBP→量化） | 128px 像素英雄 + 戰鬥動畫，取代 portraits_v3 |
| 神明（6） | 平滑動漫，違反鐵則 | **PixelLab** 重製 or 封存為 cut-in key-art | 同屏版＝像素；展示版＝量化插畫 |
| 卡面（cards_v3） | 粗像素密度不一 + 實心背景 + 烤入 AI 亂碼 | **NBP** 母圖→量化 + Recraft 卡框 | 256 插圖區、透明、清亂碼、入框 |
| 圖示/卡框/UI（139 SVG） | 風格散、部分 HALO | **Recraft** | 單一風格向量、真去背、64 格 |
| 場景背景 | 美但密度比角色細 | **NBP**→降採對齊密度 | 與角色同像素密度 |
| FX | 土砲 | **Godot 素材庫** shader/粒子 + PixelLab 爆破 | 描邊/溶解死亡/像素完美 |
