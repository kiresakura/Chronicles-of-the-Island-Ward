# UI 素材交付驗收清單

## 每個素材都要回答
- 檔名是否符合規範？
- 有沒有 state 版本？
- 是否標註用途？
- 尺寸是否與 token 相容？
- 深底 / 暖底上都可見嗎？
- 手機縮小後還清楚嗎？
- Aida 能不能直接接到 Godot？

## 卡牌
- 稀有度差異夠明確
- 費用角標清楚
- 內文區可讀

## 按鈕
- idle / pressed / disabled 都有
- 按下感夠明確
- CTA 與次級按鈕區別夠大

## 面板
- 安全內容區清楚
- 不會花到吃字
- 可做 9-slice

## 地圖
- 節點類型一眼可分
- 可達與已選不混淆

## HUD
- HP / Armor / Energy 色彩差異明確
- 數字不會被背景吃掉

## 特效
- 不喧賓奪主
- 深色背景清楚
- 手機可承受
