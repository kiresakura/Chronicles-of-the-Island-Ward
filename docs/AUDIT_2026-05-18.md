## 🔴 P0 — 新發現的 run-blocking bug（已修）

### C1. FileLoader 不遞迴 → 鎮島錄所有子資料夾內容從未載入

**根因**：`FileLoader.get_files_in_directory()` 用 `DirAccess.get_files()`，**不遞迴**。
`external/mod_info.json` 只註冊到頂層（如 `external/data/cards/`），但鎮島錄依 PRD 7.3
把內容分在子資料夾：

- `cards/tongji/`、`cards/str/`
- `artifacts/tongji/`、`artifacts/common/`、`artifacts/str/`
- `enemies/act1_mountain/`
- `events/act1_mountain/`

結果：這些 JSON **全部沒被載入**。乩童起手卡（card_tongji_punch…）、平安符、
山豬精等敵人、覆寫過的 act1 events —— 通通沒生效。

**為何 2026-05-17 audit 沒抓到**：當時 run 用的是 STR `character_red`，其卡牌/遺物
全來自 `add_test_*()` 程式生成器（不依賴 JSON），剛好繞過這個 bug。一旦改用乩童
（走 JSON）就會缺卡 / 缺遺物。

**修法**：`FileLoader` 新增 `get_json_files_in_directory_recursive()`，遞迴掃子資料夾
並只回傳 `.json`（順便濾掉 .gitkeep/.import 雜訊）；`load_read_only_data()` 改用它。
函式本體採新增而非改寫，維持 STR upstream 追更能力。

**驗證**：新測試 `test_tongji_starting_content_resolves` 從 FAIL → PASS。

## 🟠 P1 — 角色選單預設選到 character_red（已修）

**根因**：`Global._ready()` 先呼叫 `add_test_characters()`（STR Red/Blue/Green/Orange Guy）
寫入 `_id_to_character_data`，JSON 載入在後；角色選單 `CharacterButtonContainer`
取 `_id_to_character_data.keys()` 第一個為預設 → 永遠是 character_red。

**修法（資料驅動，最小框架改動）**：
- `Global._ready()` 註解掉 `add_test_characters()` / `add_test_player_data()`
  兩行呼叫（函式本體不動，維持 upstream 追更；這是 STR「已有真資料」的預期流程）。
- 刪除 `external/data/characters/character_red|blue|green.json`（僅改名 patch，
  生成器停用後會變成無 player_id 的壞角色）。
- 結果：角色表只剩 `character_tongji` → 選單唯一且預設為乩童。

**附帶解決**：起手遺物英文（AUDIT_2026-05-17 P2）—— 乩童起手是平安符（完整中文 JSON），
character_red 退場後不再顯示英文 "Artifact Block on Attacks"。

**驗證**：`test_only_cotiw_characters_registered`、`test_tongji_is_sole_character` PASS。

### B6. 主選單 Settings 按鈕 disabled —— 非 bug，屬 V5 設計

真正的設定畫面屬 Phase 2+ 範圍。維持現狀（停用），不視為待修 bug。

### P3. Reward 池含 STR placeholder 遺物 —— 內容覆蓋率問題，非程式 bug

遞迴修復後 `artifacts/str/*.json` 會把 STR 測試遺物本地化為中文（進財符…），
以 `color_white` 落入 `artifact_pack_neutral`。這是 **過渡期 placeholder 內容**
（符合 CLAUDE.md「美術/內容 placeholder」哲學），非 crash、非 run-blocker。

不在本批次「清掉 STR 遺物」的理由：
1. `artifacts/str/*.json` 是 patch（無 script_path），強拆會弄壞遺物本體。
2. 重設遺物顏色會連帶清空 boss/shop 獎勵池 → 觸及**平衡**，依 CLAUDE.md §9
   平衡決策不由接手者擅自決定。
3. 屬 PRD P3「內容擴充」範圍（每角色 34+ 遺物），應在 Sprint 內容階段處理。

**建議**：Sprint 內容階段為鎮島錄遺物建獨立 color/pack，再評估是否排除 STR 白池。
