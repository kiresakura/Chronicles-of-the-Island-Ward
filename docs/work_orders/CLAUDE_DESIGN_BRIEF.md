## 1. 產品一頁速覽

**鎮島錄 / COTIW** — 台灣民俗主題肉鴿卡牌手遊。Godot · **橫向 1200×700 觸控** · F2P,**不做 gacha、不賣戰力**(只賣外觀 / 角色解鎖)。
- **核心動詞**:破煞(削煞盾爆發)、合符(卡牌合成升階)、請神/降乩(神明大招)、擲筊(問神節奏)、遶境(出巡地圖)、修廟(meta)、**五營戰**(壇主把神將擺進東南西北中五營,攔截來煞、護母壇)。
- **美術定位**:**Temple Neon Pixel**(像素 + 霓虹 + 廟會),霓虹是稀缺資源。
- **市場**:台灣/港澳/華語圈為主 + 日本(妖怪)/英語 indie。
- **現況**:結構已落地、賣相未到——三畫面(新一局/神示供桌/五營戰)目前暗紅疊暗紅、洗白、五營讀不出敵我。**這就是你要重生的對象。**

## 2. 市場致勝策略（2025–26 調查 → COTIW 怎麼用）

> 這八條是當前最成功作品的共通法則。**每條都要在交付物裡看得到。**

1. **藝術指導即護城河**(Reverse: 1999)— 一致、文化扎根、氛圍化的視覺語言 + 符號學 + 電影感角色展示,造就辨識度與記憶點。
   → COTIW:把 Temple Neon Pixel + **台灣符號系統**(符紙/籤/筊杯/八卦/燈籠/廟埕/八家將)做成**全屏一致的世界**,不是換皮。
2. **Juice 勝過預算**(Balatro,獨立爆款)— 紀律化層次 + 精準回饋時機 + 一致風格,讓「數值變化即時可讀 + 升階快感」像拉霸中獎。小團隊靠這個贏。
   → COTIW:破煞/合符/請神/擲筊**每一拍**都要「卡牌砸下 + 震屏 + 數字跳動 + 音效 tick」。這是你最該砸的地方。
3. **卡是主角、UI 退讓**(Marvel Snap)— 暗色「鋼琴玻璃」+ 全像 UI 永遠襯托卡;外觀升階(parallax/燙金/動態 FX)當進度與變現。
   → COTIW:**籤 / 神將 / 卡**是視覺中心,UI 退到襯托;**燙金箔/動態卡背**當 F2P 安全變現。
4. **揭示的爽在「揭示之前」**(gacha 心理學/RPE)— 多巴胺在揭示**前**;build-up → 延遲 → 音效漸強 → 慢推鏡 → 招牌台詞 → 爆發。
   → COTIW:**擲筊問神 → 上上籤金光、降乩 cut-in、開壇**都要編排期待。**用在「玩出來的」時刻,不是付費牆**(契合不做 gacha)。
5. **2026 UI 趨勢**:乾淨 HUD 去雜訊、微互動/動態介面、diegetic(融入世界)、無障礙(對比/字級/色盲)、**簡短可選教學**。
   → COTIW:戰鬥 HUD 砍雜訊(非戰鬥畫面別塞戰鬥資源);供桌/五營羅盤要像「世界的一部分」不是選單。
6. **Onboarding/留存**:Day1 **77% 流失**;**playable 邊玩邊學**(非文字牆)、Day-1 大禮、每日習慣回圈、漸進/情境教學。
   → COTIW:第一場前 90 秒邊玩邊懂破煞/請神;**第一次擲筊與第一次破煞必須是「哇」**;首日送好禮。
7. **HD-2D / 高級像素**:像素 + 現代光影/粒子/景深 = 高級感,不廉價復古(Sword of Convallaria、Octopath HD-2D)。
   → COTIW:像素精靈 + 霓虹輝光 + 燭光/香煙粒子 + 景深暗角,讓 Temple Neon Pixel 看起來**貴**。
8. **台灣民俗即國際辨識度**(Devotion、Nine Sols、The Rewinder、設計師 Godkidlla)— 廟宇符號、繁複裝飾、紋理、「有意義的繁盛」是文化標記;authenticity 帶來辨識。
   → COTIW:大膽用裝飾與紋理,別怕「繁」;考據要扎實。這是你打國際的本錢。

## 3. 設計委託（交付物）

**A. 視覺語言 / 設計系統**
- 色票:硃砂紅 `#8e2a1c` / 燙金 `#e8c46a` / 宣紙米 `#f0e4c8` / 漆黑 `#1a0f0d` / 玉青 `#46c99a`(吉/得位);**禁暗紅疊暗紅**——大面積暗底必用燙金/宣紙拉出高對比焦點。
- 字體階層、像素網格規格、**霓虹光用法(稀缺,只給英雄焦點與招牌時刻)**。
- 母題庫:符/籤/筊/八卦/燈籠/五營羅盤/八家將/廟埕剪影/香煙燭火。
- UI chrome:硃砂帶標題 + 燙金細框 + 宣紙底卡 + 暗角。亮/暗雙模式。
- **無障礙**:WCAG 對比、最小字級、色盲安全(別只靠紅綠分敵我)。
- 元件庫:按鈕/卡/籤/面板/HUD/modal/tooltip/分頁/下拉,含按壓/選中/鎖定/載入態。

**B. 關鍵畫面高保真重設計**(全屏一致,亮/暗 + 三解析度 1244×700 / 1515×700 / 1200×900)
1. **主畫面·正殿** — 辨識度第一印象 + 每日回禮鉤子。
2. **新一局** — 角色立繪作英雄焦點。
3. **神示供桌** — 籤詩(籤名+四字籤詩)+ 籤運分級(上上→下下色/飾/光)+ 擲筊揭示。
4. **🔴 五營戰(最高優先)** — 母壇居中十字、東南西北四營守四 lane、中營 reserve;**一眼分敵我**(我營金框/來煞紅環/母壇告急轉紅);常駐圖例、去 `???`、破煞 juice。
5. **遶境地圖** — 節點類型一眼可辨、路線敘事感。
6. **結算/獎勵揭示** — 用 §2.4 的期待編排。

**C. 招牌時刻(Motion / Juice 規格)** — 每個給 timing 曲線 / 震屏幅度 / 粒子 / 音效鉤點 / ≤1.5s 可跳過:
破煞碎盾、降乩 cut-in、合符升階、擲筊(聖/笑/陰)、上上籤金光、母壇告急、勝利結算。

**D. FTUE 首次體驗流程** — 前 90 秒分鏡:邊玩邊學破煞/請神、第一次擲筊的「哇」、Day-1 大禮、第二場的鉤子。

**E. 變現·外觀分級** — 燙金箔/動態卡背/神將皮膚/降臨動畫 skin 的視覺稀有度階梯(**完全不碰戰力**)。

**F. 辨識度宣言(一頁)** — 三條「只有這款會這樣做」的視覺簽名 + 三張隨機截圖測試(陌生人能否說出「台灣廟會主題」「這是這款」)。

## 4. 評估標準（每個交付都要過,任一不過就重做）

- **視覺饗宴**:每屏一個英雄焦點 + 層次分明 + 關鍵時刻有「一拍爽」。
- **不混亂不沮喪**:5 秒可解、有圖例、乾淨(無溢出/截斷/modal 透背景/鬼影)。
- **辨識度**:一眼是這款、一眼是台灣民俗。
- **商業尺(調查背書)**:juice 即時可讀(策略 2)、卡為主角(3)、揭示有期待(4)、HUD 乾淨(5)、FTUE 不流失(6)、無障礙過關(5)。

## 5. 硬約束（不可違反）

- 橫向 1200×700 觸控;最小點擊區 **88×88**;不依賴 hover;瀏海/安全區不截斷。
- **名詞紅線**:用 煞盾/破煞/合符/敕符/降乩/擲筊/五營/籤運;**禁** 韌性/弱點擊破/升階/終結技、禁英文外洩。
- **變現紅線**:不做 gacha、不賣戰力;揭示爽感只用在「玩出來的」時刻。
- Temple Neon Pixel 像素動漫風;**霓虹稀缺**。
- **文化敬意**:民俗符號考據,不褻瀆、不挪用敏感儀軌。
