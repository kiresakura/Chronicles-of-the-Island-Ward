# 原型任務:「五營戰鬥」手感驗證分支（throwaway prototype）

## 角色與定位
你是 COTIW 代理製作人兼首席工程師。先讀 `DELEGATION.md`、`CLAUDE.md`、`docs/design/formation_progression_v0.3.md`。

**這是一次手感實驗,不是正式功能。** 唯一目的:驗證「**壇主鎮守五營**」的戰鬥手感,是否真的勝過現行「抽手牌 + 花神力」的殺戮尖塔式戰鬥。**先證明好玩,才談整合。**

## 唯一假設(要被證實或證偽的東西)
> 把戰鬥核心動詞從「抽牌打牌」換成「佈陣 / 調營 / 守 lane / 擲筊節奏」,在手機橫向上**更有策略感、更好玩**,且新手 2 分鐘內看得懂。

## 範圍(嚴格)
- **開新分支** `prototype/five-camp`,從當前主線切出。**完工不直接合併主線。**

- 複用既有零件,不重造:`FortuneSticks.gd`(擲筊)、`DeityInvocationSystem` 觸發鍵、`RitualLoadout.resolve_deity_queue()` 當開場佈陣。

## 原型要做的最小可玩切片(刻意砍到只剩核心)
1. **棋盤**:3 個營(中營 + 2 方位營)。先不做完整五營、不做五行相生相剋。
2. **佈陣 / 調營**:把 2–3 個神明/家將單位放進營、回合間移防。
3. **lane 煞**:煞從方位推進,該營攔截;營空 → 直擊**母壇 HP**(取代玩家元神)。
4. **節奏閘**:每回合 `擲筊` 一次——聖筊加速(多一動作)、笑筊卡住、陰筊某 lane 暴衝。
5. **得位(二元最輕版)**:單位屬性與營相符 → 該營效果 +X%(數值在資料層)。**不做**相生相剋。
6. **勝負**:撐過 N 波 = 勝;母壇 HP 歸零 = 敗。一場 3–5 分鐘。
7. 一個橫向 1200×700 可玩畫面,營位點擊區 ≥ 88×88,不依賴 hover。

**不要做**:敕封/封神榜、緣分合祀網、完整五行、修廟接線、美術打磨、平衡調參、存檔。這些是手感過關後才碰。
