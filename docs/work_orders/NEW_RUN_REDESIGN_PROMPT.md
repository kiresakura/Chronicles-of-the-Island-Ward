## 目標設計(驗收基準)
版面切三區、單向動線 **① 選將 → ② 設定 → ③ 開壇**:

- **① 你是誰(左)**:單一「英雄面板」是角色資訊的**唯一真相來源**——立繪、姓名、一句定位、元神 / 銀兩、3 個特性標籤、起手法器(平安符,**完整不截斷**)。下方「陣容列」只負責切換角色。**刪除**右側 / 中央的重複描述。
- **② 怎麼開壇(右上)**:難度(− / 數字 / + stepper + 一行說明)、模式(標準 / 易 / 無盡 / 自訂 分段選擇,取代謎之清單,**須有明確選中態**)、護壇、法器(各一列可點)。**一張卡框住**,讀成一個單位。
- **③ 開壇(右下)**:巨大、獨佔、全場最高對比的「開始開壇」CTA。種子收進「進階」(**預設摺疊**)。

設計原則:
- **減法 + 單一真相來源**:同一資訊只出現一次。
- **霓虹是稀缺資源**:只用於「選中角色光環」與「開始開壇」,其餘留暗,對比才出得來(這才是 Temple Neon Pixel)。
- **鎖要勾引不要訓斥**:紅叉 → 剪影 + 解鎖進度章(例:再勝 3 場),用既有勝場 / act 資料驅動。
- **主題服務功能**:保留「開壇」風味當標籤,互動要一眼讀成「點頭像選將」,刪掉暗示隨機的燈落文案。
- **正文永不截斷。**
